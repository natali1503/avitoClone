## Описание проекта

**Доска объявлений** — веб-приложение для размещения и управления объявлениями с многошаговыми формами, системой фильтрации и продвинутым управлением состоянием.

Приложение поддерживает три категории объявлений:

- **Недвижимость** (квартиры, дома, офисы)
- **Авто** (легковые автомобили)
- **Услуги** (профессиональные услуги)

---

## Технологии

### Frontend
- **React 19** с **TypeScript**
- **Redux Toolkit** — управление глобальным состоянием
- **React Hook Form** — управление формами с валидацией
- **React Router v7** — клиентская маршрутизация
- **Material-UI (MUI)** — UI компоненты
- **Axios** — HTTP клиент

### Backend
- **Node.js** + **Express** (TypeScript)
- In-memory storage для данных

### Инструменты разработки
- **Vite** — сборщик проекта
- **Jest** + **React Testing Library** — тестирование
- **Docker** + **Docker Compose** — контейнеризация
- **Nginx** — веб-сервер для production

---

## Ключевые особенности

- ✅ **Многошаговые формы** с валидацией и сохранением черновиков в localStorage
- ✅ **Типизированная архитектура** с использованием discriminated union types для разных категорий
- ✅ **Single Source of Truth** паттерн для управления состоянием форм
- ✅ **Дизайн** с использованием Material-UI
- ✅ **Обработка ошибок** через toast-уведомления
- ✅ **Unit и Integration тесты** с использованием Page Object Model
- ✅ **Docker-ready** для простого развертывания

## Установка и запуск

1. Клонируйте репозиторий:
   ```sh
   git clone https://github.com/natali1503/adBoard.git
   ```
2. Перейдите в каталог проекта:
   ```sh
   cd adBoard
   ```
3. Запустите проект с помощью Docker:
   ```sh
   docker-compose up --build
   ```

## Функциональность

### 1. Размещение объявлений
- Многошаговая форма с валидацией полей
- Динамические поля в зависимости от выбранной категории
- Загрузка изображений
- Автосохранение черновика в localStorage

### 2. Список объявлений
- Отображение всех объявлений с пагинацией (5 объявлений на странице)
- **Динамическая фильтрация**: поля фильтров меняются в зависимости от выбранной категории
- Фильтрация по названию и категории
- Сортировка результатов

### 3. Просмотр объявления
- Детальная карточка с полной информацией
- Возможность редактирования и удаления
- Навигация между объявлениями

### 4. Редактирование объявлений
- Редактирование в рамках одной категории (PUT-запрос)
- Смена категории с автоматическим пересозданием объявления
- Сохранение черновика при незавершенном редактировании

## Тесты

Проект покрыт unit и integration тестами с использованием **Jest** и **React Testing Library**:

- Создание объявлений (все три категории)
- Отображение списка объявлений
- Детальный просмотр объявления
- Фильтрация объявлений
- Навигация между шагами формы

**Запуск тестов:**
1. Перейдите в каталог проекта:
   ```sh
   cd client
   ```
2. Выполните команду
   ```bash
   npm run test
   ```
